# CompanionBridge — мост к LLM

Локальный HTTP-сервер на Python (arm64). Через него мод говорит с Claude, распознаёт речь и озвучивает реплики. Мод запускает мост сам. Установка описана в [основном README](../README.md#3-мост).

## Файлы

| Файл | Что делает |
|---|---|
| `bridge.py` | HTTP-сервер, запросы к Claude (поток, JSON `{say, plan, remember}`), настройки характера, упреждающие ответы на голос |
| `memory.py` | Память для каждого мира и персонажа: последние реплики, факты, летопись, журнал событий. Фоновые «размышления» обновляют факты и летопись |
| `voice.py` | Микрофон (`sounddevice`), распознавание Parakeet на MLX, синтез Silero или Piper, очередь озвучки по предложениям |
| `prompts/roles/*.md` | Роли: `viking`, `skald`, `mentor`, `jester`, `friend`, `custom`. `{name}` заменяется именем компаньона |
| `prompts/rules.md` | Что он умеет (шаги плана), сундук, память, события, как читать сводку |
| `prompts/lore.md` | Земли, боссы и основы Валхейма — опора для советов |
| `mic_check.py` | Проверка доступа к микрофону. Запускается лаунчером, код выхода 0, 1 или 2 |
| `setup.sh`, `requirements.txt` | Окружение `.venv` и модели в `data/voices/` |
| `.env.example` | Образец `.env` с ключом Anthropic |

В `data/` (не в git) лежат модели, `memory/<мир>__<персонаж>.json` (память, удали файл — и он забудет этот мир), `bridge.log` и `mic_check.log`. Старый общий `memory.json` при первом запуске переносится в память первого мира.

## Промпт и кэш

Системный промпт состоит из двух блоков: роль, манера, правила и знания (меняются только с настройками) и память мира (меняется только после размышлений). Оба помечены `cache_control`, поэтому каждая реплика читает около 5 тысяч токенов из кэша, а платит полную цену только за историю, сводку и саму фразу. В лог пишется `cache r/w`.

«Мышление» из настроек выбирает модель и усилие: `fast` — `claude-haiku-5-5`, effort `low`; `thoughtful` — Haiku, `medium`; `smart` — `claude-sonnet-5-5`, `low`.

## Ключ Anthropic

Порядок поиска:
1. переменная окружения `ANTHROPIC_API_KEY`;
2. `ANTHROPIC_API_KEY` в `.env`;
3. файл, указанный в `ANTHROPIC_API_KEY_FILE`, — из него берётся переменная с именем `ANTHROPIC_API_KEY_NAME` (по умолчанию `ANTHROPIC_API_KEY`). Так ключ остаётся в одном месте.

## Запуск вручную

```sh
.venv/bin/python bridge.py                    # сервер на 127.0.0.1:8765
.venv/bin/python bridge.py --selftest "Привет" # один запрос без сервера
.venv/bin/python bridge.py --selftest "Собери малины" --state state.json  # со своей сводкой
.venv/bin/python bridge.py --help             # все параметры
```

Основные параметры:

| Параметр | Что задаёт |
|---|---|
| `--port`, `--name` | Порт и имя компаньона |
| `--voice`, `--silero-pitch`, `--silero-tempo`, `--volume` | Голос |
| `--no-tts`, `--no-fillers` | Без озвучки; не хмыкать, пока думает |
| `--stt-device cpu\|gpu` | Где распознавать речь |
| `--parent-pid` | Завершиться вместе с игрой |
| `--config FILE` | JSON с настройками характера при запуске (мод пишет его сам) |
| `--fake-mic DIR`, `--mute`, `--memory-dir DIR` | Для тестов: wav-файлы вместо микрофона, озвучка без звука, отдельная папка памяти |

Мод передаёт эти параметры из своего конфига.

## HTTP API

Все запросы и ответы — JSON, сервер слушает только `127.0.0.1`.

| Метод | Путь | Зачем |
|---|---|---|
| GET | `/health` | Мост жив и готов ли голос |
| POST | `/v1/event` | Реплика игрока или событие мира (`kind`, `text`, `state`). Ответ: `{say, plan: [{do, what, count, kind, note}]}` |
| POST | `/v1/note` | Событие игры для памяти (`text`, `state`) — без ответа модели |
| POST | `/v1/config` | Настройки: `name`, `role`, `role_custom`, `length`, `humor`, `rudeness`, `chattiness`, `thinking`, `memory`, `tts`, `voice`, `tone`, `tempo`, `volume`, `fillers`. Голос пересобирается в фоне |
| GET, POST | `/v1/memory` | Что помнит о мире из `state`: факты, летопись, размер истории |
| POST | `/v1/memory/forget` | Стереть память о мире из `state` |
| POST | `/v1/voice/start` | Начать запись с микрофона (`state`, можно `test_audio`) |
| GET, POST | `/v1/voice/partial` | Распознанный текст и уровень звука. POST ещё и обновляет `state` |
| POST | `/v1/voice/stop` | Закончить запись: финальный текст, ответ, время до ответа |
| POST | `/v1/voice/cancel` | Отменить запись |
| POST | `/v1/speech/stop` | Замолчать (перебить) |

`state` — сводка от мода: мир, время суток, биом, дом игрока, здоровье и еда, что у игрока в мешке, враги, лес и камень, растения и дичь рядом (сколько и где ближайшие), содержимое ближайшего Сундука Бьёрна, печи рядом (топливо, очередь, готовое), сколько построек повреждено, известные места и подписанные метки игрока на карте (расстояние и сторона света), что у компаньона в мешке, чем он занят и что дальше по плану, лук и стрелы. Мост превращает её в короткий текст для модели.

Шаги плана (`do`): `follow`, `come`, `stay`, `attack`, `gather_wood`, `mine`, `pick`, `hunt`, `loot`, `give_items`, `store`, `fetch`, `combat_style`, `mark_place`, `forget_place`, `guard`, `repair`, `smelt`, `collect`. Модель пишет `what` по-русски, как в сводке, а мод сопоставляет по основам слов. У `mark_place` есть ещё `kind` (`home`, `portal`, `resource`, `danger`, `landmark`) и `note` — что игрок сказал о месте.

**Озвучка.** Перед синтезом числа пишутся словами, латиница — кириллицей (Silero молча выбрасывает и то и другое), а фраза без русских букв пропускается. Ошибка синтеза одной фразы не обрывает озвучку.

**Смена роли.** Когда роль, своё описание или имя меняются, в историю мира ставится пометка, что реплики выше сказаны в прежней роли. Иначе модель подражает старым репликам.

**Упреждающие ответы.** Пока игрок держит R, мост распознаёт речь по кусочкам. На паузе он заранее отправляет запрос модели с текущим текстом. Если к моменту отпускания R текст не изменился, а обстановка (груз, режим, враги) та же, готовый ответ отдаётся сразу.
